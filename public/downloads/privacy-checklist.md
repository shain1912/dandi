# 배포 전 개인정보 셀프점검표 (Dandi 임시 기준)

> **안내:** 교육청의 Agentic AI 서버·배포·개인정보보호 가이드라인은 아직 확정되지 않았습니다(PRD 미결 사항 Q2).
> 이 점검표는 확정 전까지 쓰는 **임시 기준**이며, 가이드라인이 확정되면 그 내용으로 바뀝니다.
> 이 점검표는 학교 운영위원회 등 학교 내부 승인 절차를 대신하지 않습니다.

Dandi에 미니앱을 등록할 때(웹 등록 화면 또는 `dandi publish`) 아래 5개 항목을 반드시 입력합니다. 입력한 결과는 앱 카드에 "개인정보 처리 여부"로 표시됩니다.

## 필수 5개 항목

| # | 항목 | 답 | 확인 방법 |
|---|---|---|---|
| 1 | 학생 개인정보를 수집·처리합니까? | 예 / 아니요 | 이름, 학번, 연락처, 사진, 생년월일, 주소, 건강·상담 기록을 입력받거나 화면에 불러오면 "예" |
| 2 | 데이터를 어디에 저장합니까? | 자유 기재 | 예: 저장 안 함 / 기기 브라우저(localStorage) / Supabase(서울 리전) / 구글 시트 |
| 3 | 얼마 동안 보관합니까? | 자유 기재 | 예: 해당 없음 / 7일 / 학기 말 삭제. "무기한"이면 삭제 시점을 정하십시오 |
| 4 | 입력 내용을 외부로 전송합니까? | 예 / 아니요 | 해외 AI API, 외부 설문·분석 서비스, 이메일 발송으로 내용이 나가면 "예" |
| 5 | 학교 내부 승인이 필요합니까? | 예 / 아니요 | 1번이 "예"이면 반드시 "예". 승인 전에는 공개 등록하지 않습니다 |

## 먼저 할 일: 받지 않는 설계

개인정보는 잘 지키는 것보다 **처음부터 받지 않는 것**이 가장 안전합니다.

- 이름 대신 **좌석 번호, 모둠 번호, 가명**을 씁니다. (예시: 템플릿 갤러리의 "학급 출석 체크" 앱)
- 점수·결과는 화면에만 보여 주고 저장하지 않습니다.
- 꼭 저장해야 한다면 **기기 브라우저에만**, **짧게**(예: 7일) 보관하고 자동 삭제합니다.
- 교사 이름도 개인정보입니다. 여러 사람이 보는 화면에는 약칭(예: 국어A)을 쓸 수 있게 합니다.
- 결석 사유, 상담 내용, 건강 정보 같은 민감한 정보는 미니앱으로 다루지 않습니다.

## 외부 전송 점검

- AI 기능은 Dandi AI 게이트웨이를 거쳐 호출합니다. 게이트웨이는 교육청이 허용한 모델만 통과시키고, 프롬프트 속 전화번호·주민등록번호 등을 호출 전에 가립니다.
- 개인 API 키로 해외 AI API를 직접 부르지 않습니다.
- 외부 글꼴·아이콘 CDN, 분석(추적) 스크립트도 방문 기록을 외부로 보냅니다. 필요 없으면 넣지 않습니다.

## 저장소를 쓸 때 (Supabase 등)

- 데이터베이스 지역을 확인하고 2번 항목에 적습니다(예: 서울 리전).
- 본인 글·기록만 수정·삭제되게 권한(RLS 등)을 설정합니다.
- service_role 키 같은 관리자 키를 브라우저 코드에 넣지 않습니다.
- 시험·연수용 프로젝트에는 실제 학생 데이터를 넣지 않습니다.
- 보관 기간이 끝나면 지우는 방법(수동 또는 자동)을 정해 둡니다.

## 코드로 확인하기 (AI 코딩 도구에 요청)

다음 문장을 AI 코딩 도구에 붙여 넣으면 점검을 도와줍니다.

```text
이 프로젝트를 배포 전에 개인정보 관점에서 점검해 주십시오.
1) 이름·학번·전화·주소·사진을 입력받는 곳, 2) 외부로 요청을 보내는 코드(fetch, axios, form action, AI API),
3) localStorage·쿠키·DB에 저장하는 데이터와 보관 기간, 4) 코드에 적힌 키·토큰, 5) 분석 스크립트·외부 CDN을
파일 위치와 함께 표로 정리하고, 개인정보를 받지 않도록 고칠 방법을 제안해 주십시오. 코드는 아직 고치지 마십시오.
```

## 등록 전 최종 확인

- [ ] 5개 항목을 모두 답했습니다.
- [ ] 1번이 "예"라면 학교 내부 승인을 받았거나, 승인 전까지 공개하지 않습니다.
- [ ] 화면 첫머리에 개인정보 처리 방식을 한 줄로 안내했습니다(예: "입력 내용은 이 기기에만 저장됩니다").
- [ ] 코드와 저장소에 비밀 값(API 키, 토큰, `.env`)이 없습니다.
- [ ] 연수·시연용 데이터에 실제 학생 정보가 없습니다.
