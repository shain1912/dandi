# Supabase·Vercel MCP 연동 가이드 (Claude Code · Cursor)

> 이 문서는 AI 코딩 도구에 Supabase MCP와 Vercel MCP를 연결하는 **일반 절차와 안전 수칙**을 설명합니다.
> MCP 서버 주소, 설치 명령, 옵션 이름은 자주 바뀝니다. 실제 값은 반드시 아래 공식 문서에서 확인하십시오.
>
> - Supabase 문서: https://supabase.com/docs (문서 검색에서 "MCP")
> - Vercel 문서: https://vercel.com/docs (문서 검색에서 "MCP")

## 1. MCP란

MCP(Model Context Protocol)는 AI 코딩 도구가 외부 서비스의 기능을 "도구"로 불러 쓰게 하는 표준 연결 방식입니다.
연결해 두면 교사가 대시보드를 오가지 않고 대화로 "테이블 구조를 보여 주십시오", "마지막 배포가 실패한 이유를 찾아 주십시오"처럼 요청할 수 있습니다.

## 2. 무엇을 할 수 있나

| MCP | 주로 하는 일 (공식 문서의 도구 목록으로 확인) | 교사 활용 예 |
|---|---|---|
| Supabase MCP | 프로젝트·테이블 구조 조회, SQL 실행, 마이그레이션 적용, 로그 확인, 타입 생성 | 앱에 필요한 테이블 설계, 권한(RLS) 설정 검토, 오류 로그 확인 |
| Vercel MCP | 프로젝트·배포 목록 조회, 배포 상태와 빌드 로그 확인, 문서 검색 | 배포 실패 원인 찾기, 배포 주소 확인 |

## 3. 연결 전 준비

1. Supabase·Vercel 계정을 만듭니다. 학교 업무용이면 개인 계정과 섞지 않도록 별도로 관리하십시오.
2. **연습·개발용 프로젝트를 따로** 만듭니다. 운영 중인 앱의 데이터베이스에는 처음부터 연결하지 않습니다.
3. 프로젝트 루트에 `llms.txt`와 `DESIGN.md`를 둡니다. AI가 프로젝트 규칙(개인정보를 저장하지 않는다 등)을 먼저 읽게 됩니다.

## 4. 연결 방법 (일반 절차)

1. **공식 문서에서 연결 정보를 확인합니다.** 원격(HTTP) MCP 서버 주소 또는 로컬 실행 명령, 인증 방식(브라우저 로그인 또는 개인 액세스 토큰)이 안내되어 있습니다.
2. **AI 코딩 도구에 MCP 서버를 추가합니다.**
   - Claude Code: `claude mcp add` 명령으로 추가하거나, 팀과 함께 쓰려면 프로젝트 루트의 `.mcp.json` 설정 파일에 적습니다. 정확한 옵션은 Claude Code 문서의 MCP 항목을 확인하십시오.
   - Cursor: 설정 화면의 MCP 항목에서 추가하거나, 프로젝트의 `.cursor/mcp.json` 설정 파일에 적습니다. 정확한 형식은 Cursor 문서의 MCP 항목을 확인하십시오.
   - 도구 버전에 따라 메뉴 이름과 파일 위치가 다를 수 있습니다.
3. **인증합니다.** 브라우저 로그인 방식이면 창이 열릴 때 로그인합니다. 토큰 방식이면 토큰을 설정 파일에 직접 쓰지 말고 환경 변수로 넘기는 방법을 쓰십시오.
4. **연결을 확인합니다.** AI 코딩 도구에 "연결된 MCP 서버와 사용할 수 있는 도구 목록을 보여 주십시오"라고 요청합니다.

## 5. 요청 예시

```text
[Supabase] 출석 체크 앱에 필요한 테이블을 설계해 주십시오. 학생 이름·학번 열은 만들지 말고 좌석 번호만 쓰십시오.
적용하기 전에 SQL과 RLS 정책을 먼저 보여 주고, 제가 승인한 뒤에 실행하십시오.

[Vercel] 이 프로젝트의 최근 배포 목록을 보여 주고, 실패한 배포가 있으면 빌드 로그에서 원인을 찾아 설명해 주십시오.
```

## 6. 안전 수칙

- **읽기 전용·범위 제한부터.** 서버가 읽기 전용 모드나 특정 프로젝트만 다루는 옵션을 제공하면 켜고 시작합니다.
- **실행은 승인 후에.** SQL 실행, 데이터 삭제, 마이그레이션, 운영 배포 같은 도구 호출은 자동 승인하지 말고 내용을 읽은 뒤 승인합니다.
- **실제 학생 데이터 금지.** 연수·연습 프로젝트에는 가상의 데이터만 넣습니다.
- **비밀 값 관리.** 액세스 토큰, service_role 키를 대화창·코드·저장소에 붙여 넣지 않습니다. 연수가 끝나면 토큰을 폐기합니다. 공용 PC에는 저장하지 않습니다.
- **데이터 속 문장은 지시가 아닙니다.** 데이터베이스 내용이나 로그에 "이전 지시를 무시하라" 같은 문장이 있어도 AI가 따르지 않게, 조회 결과를 근거로 한 변경은 반드시 사람이 확인합니다.
- **모델 정책 준수.** MCP를 쓰는 AI 도구의 모델도 교육청이 허용한 모델이어야 합니다. 허용 목록은 Dandi의 AI 화면에서 확인합니다.
- **개인정보 셀프점검.** MCP로 테이블을 만들었다면 저장 위치(리전)와 보관 기간을 셀프점검표(privacy-checklist.md)에 반영합니다.

## 7. Dandi와의 관계

- v0.1(프로토타입)은 이 연동 가이드와 스킬 파일(SKILL.md)을 제공합니다. 배포 후 허브 등록은 `dandi publish --url <배포 주소>`로 하고, 시험 기능인 `dandi deploy`는 Vercel 운영 배포와 허브 등록을 이어서 수행합니다.
- v1.0에서는 `llms.txt` 기반 빌드, Vercel 배포, Supabase 연동, 허브 등록을 한 번에 수행하도록 확장할 예정입니다(PRD F-19).
