## 1. 주요 논의

### 1-1. AI 활용 원칙과 개인정보 가이드라인

- **AI는 교사를 지원하는 도구로** (조현식): OECD 경고 기사("AI에 과제 맡긴 학생들, 성적 1.5년 치 떨어졌다")를 공유하며 학생의 AI 의존을 우려해 제안함
- **교육청 단위 가이드라인 필요** (조현식이 창의재단 연구회 중간보고 자리에서 김종범 연구원과 나눈 대화): Agentic AI를 구현할 때 서버·배포·개인정보보호 기준을 교육청 단위로 마련하자는 내용. 조현식은 기준이 없으면 교사가 만든 결과물이 법적 문제에 걸릴 수 있다고 우려함
- **실제 사례** (배창섭): 소속 학교 교사가 만든 학생지도 앱에서 개인정보 문제가 생겨 운영위원회 통과 전까지 사용 보류

### 1-2. 플랫폼 방향 제안 (조현식, 9/27)

1. 누구나 로그인해 비용 없이 배포까지 할 수 있는 구조
2. AI API를 일정 수준까지 제공(키 지급)하고, 단일 모델이 아닌 **중국 모델을 포함한** 다양한 모델과 기능별 적용 가이드를 제공해 교사가 여기서 배운 뒤 자기 앱에 활용하도록 함 (→ 1-3 쟁점의 발단)
3. 다른 교육청 서비스는 단순 자동화·교육자료 제작 수준이므로, agentic AI답게 처음부터 배포까지 지원
4. 개발~배포 따라하기 안내와 스킬 제공, 디자인 md의 외부 연계·내부 스킬 적용 지원 ("결국 마지막 1%를 좌우하는 것은 디자인")
5. 가능하면 온프레미스 AI도 사용하게 해서 교사가 자체 AI 구축·사용법을 익히도록 함 → 보안 부담 완화 (성능·하드웨어 가능 여부는 미확인)

**다른 의견**

- 우공이산: 작업 지시서와 예시 사이트를 주고 스스로 만들어 보는 메뉴가 필요함. 서비스 제공과 교사 개발 풍토 중 후자가 우선이기를 바라지만 더 고민이 필요하다고 함
- 조현식: 교사 역량을 높이는 것과 함께 플랫폼 역량도 중요함

### 1-3. 중국 AI 모델 사용 여부 (쟁점, 미확정)

| 입장 | 주장 |
|---|---|
| 조현식 (활용) | 중국 모델은 자동화 용도, 데이터 이해·분석은 3대 모델로 구분해 사용. 위험론은 과도함: 미국에서도 도입했고, 모델 순위 1·2위 외 대부분이 중국산이며, 국내 사용금지 조치는 없고 공공기관 주의 권고만 있음. 모델별 평가와 사용처 교육도 교사단의 몫 |
| 우공이산 (배제) | 공공기관 사용은 위험하고, 일반 사용자는 구분 없이 사용할 수 있으므로 애초에 제외하자고 함. 입력한 코드·파일의 중국 서버 전송·저장, 중국법상 정부 데이터 요구 응답 의무, 국내 공공기관 다수의 업무용 사용 제한을 근거로 듦(외부 검색 결과 인용). 시의회 지적 가능성을 우려했고, 교육부가 금지했다고 말하며 장학관에게 확인을 요청함(조현식은 금지조치가 없다고 반박) |
| 배창섭 (절충) | 로컬에서 작동하는 오픈소스 모델은 국적을 가릴 필요가 없고, 온라인 API 키 방식은 구분이 필요함. 교사단이 정할 사항, 전체 협의 사항, 관 정책을 따를 사항을 나눠 논의하자고 함 |

- **진행 상황**: 배창섭이 교사단 의견은 교육청에 전달하되 교육청 입장을 받아 추진하자고 제안했고 우공이산이 동의함. 조현식은 명시적으로 동의하지 않았고 모델 평가·사용처 교육이 필요하다는 취지를 다시 밝힘. 배창섭은 이 문제를 주요 의제로 논의하자고 제안함
- **소통 에티켓**: 교사단 방에서 "ㅋㅋ" 표현을 자제해 달라는 요청이 있었고 조현식이 사과함

### 1-4. 10월 연수 소통 채널 (미정)

- 조현식: 지금처럼 헤더방을 두고 학교급별 방을 따로 만들자고 함. 지난해 프롬프트 엔지니어링 통합방에서 친한 사람끼리 모여 학교급에서 일어난 일을 뒷담화하는 문제가 많았음
- 배창섭: 학교급별 방과 전체방을 함께 두자고 함(전체 공지·협의 사항이 있기 때문)
- 우공이산: 올릴 때 학교급을 체크하고 학교급별로 필터링하자고 제안함(카톡방인지 플랫폼 게시 기능인지는 불분명). 메이커 분야는 단톡방 하나로 문제없이 운영 중
- 결론 없이 추가 논의하기로 함
